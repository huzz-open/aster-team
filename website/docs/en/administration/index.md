# Deployment roadmap

Follow this sequence for a new deployment. For an existing installation, go directly to the relevant maintenance guide.

1. [Before you install](preparation.md): platform, package, digest, permissions and network.
2. [Installation](installation.md): root, access settings, initial credentials and first login.
3. [Product authorization](licensing.md): check free rights, import paid authorization or renew.
4. [Manage access](management.md): upstream connections, models, members and quotas.
5. [Runner nodes](runners.md): install and check dedicated execution nodes when needed.

## Existing installations

- [Daily checks](daily-checks.md): service status, diagnostics and logs.
- [Backup, upgrade and restore](backup-upgrade.md): preparation, maintenance and recovery.
- [Troubleshooting](troubleshooting.md): page, Runner, license, request and quota problems.

Full parameters and command effects are in [aster-team-cli reference](/en/tools/aster-team-cli/commands). Member computers use [client tools](/en/guides/asterctl); API users can [make a first request](/en/start/quickstart).
