# Aster Team documentation

Deploy Aster Team, manage team access to models, or start using an existing installation.

## Deploy and administer

- [First deployment](/en/administration/): prepare the environment, install and log in.
- [Product authorization](/en/administration/licensing): import, renew or switch to free.
- [Manage access](/en/administration/management): connect upstreams and configure models and members.
- [Backup, upgrade and restore](/en/administration/backup-upgrade): plan maintenance and verify the result.
- [Troubleshooting](/en/administration/troubleshooting): diagnose service, Runner, license and request problems.

## Connect and call

- [Client tools](/en/guides/asterctl): configure Codex or Claude.

- [Make your first request](/en/start/quickstart): base URL, key, and model.
- [Responses API](/en/api/responses): input, output, tools, streaming, and errors.
- [Model quick reference](/en/models/): see what changes when you switch models.
- [Images API](/en/api/images): generation and editing are distinct operations.
- [OpenAPI 3.1 specification](/openapi.yaml): request and response schemas for client generation.

Public field rules describe compatibility. Your administrator’s model grants, enabled models, and active connections determine what you can call in your installation.
