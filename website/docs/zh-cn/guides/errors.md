# 错误码

| HTTP 状态 | 含义 | 建议处理 |
| --- | --- | --- |
| `400` | 请求字段或参数组合无效 | 对照所选协议和模型参数说明修改请求。 |
| `401` | API Key 缺失或无效 | 检查认证头和 Key 状态。 |
| `403` | 当前成员无权调用该模型 | 在成员模型页面确认授权，或联系管理员。 |
| `404` | 端点或公开模型 ID 不存在 | 检查 Base URL、接口路径和模型 ID。 |
| `429` | 额度不足或请求过快 | 查看额度，降低并发后重试。 |
| `502` / `503` | 上游暂时不可用 | 保留请求 ID，稍后按退避策略重试。 |

错误正文会说明失败字段或授权原因。不要只根据状态码猜测问题。
