# 常见问题

## 为什么模型 ID 与厂商名称不同？

Aster 使用部署方配置的公开模型 ID。它是调用契约的一部分，可以与上游内部型号不同。始终从成员模型页面复制。

## 为什么管理员开放了模型，我仍然不能调用？

模型需要同时处于部署开放状态，并被授权给当前成员。成员模型页面只显示你能使用的模型。

## 三种文本协议应该选哪一个？

新项目优先使用 Responses；迁移常见 OpenAI Chat SDK 时使用 Chat Completions；Anthropic 客户端使用 Messages。切换协议时字段名会变化，请查看模型详情。

## “自动转换”是什么意思？

Aster 会转换字段名或受支持的取值。转换不能保持语义时，请求会在发送到提供商之前被拒绝。
