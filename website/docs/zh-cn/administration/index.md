# 部署路线

首次部署按以下顺序进行；已有实例可以直接进入对应维护指南。

1. [安装前准备](preparation.md)：确认平台、包、摘要、权限和网络。
2. [安装部署](installation.md)：设置安装根与访问入口，保存初始凭据并首次登录。
3. [产品授权](licensing.md)：检查免费授权，按需导入付费授权或续期。
4. [管理与使用](management.md)：接入上游、开放模型、配置成员及额度。
5. [Runner 节点](runners.md)：需要独立执行节点时安装并检查连接。
